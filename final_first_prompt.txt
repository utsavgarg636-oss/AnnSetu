# ANNSETU (अन्नसेतु) — MASTER FULL-STACK SYSTEM & UI SPECIFICATION

## 0. ARCHITECTURAL MANDATES & GUARDRAILS
1. **Monorepo Architecture:** Maintain a clean workspace containing `backend/`, `ml-service/`, and `frontend/`.
2. **Shared Backend & Real-Time Sync:** All three dashboards (`/admin`, `/host`, `/ngo`) share a single backend and database. Real-time synchronization must occur instantly via **Socket.io**.
3. **Verified NGO Restriction Rule:** Matching, radius escalation, and the NGO identity switcher must **strictly only draw from the list of verified, admin-approved NGOs** (`is_approved = true` and `fssai_verified = true`). Unapproved or pending NGO registrations must be filtered out of all operational feeds until approved by the Admin.
4. **Surprise Feature Extensibility:** Include the designated extensibility hooks (`surpriseFeatureSlot.js` and `DynamicFeatureSlot.jsx`) to allow future drop-in features without rewriting core schemas or routing.
5. **Strict UI/UX Isolation:** 
   - **Host Dashboard (`/host`):** Warm Cream (`#F7F5EC`) & Forest Green (`#245C43`) with organic bento grids, botanical accents, and a 2-minute posting form.
   - **NGO Dashboard (`/ngo`):** Pale Lilac (`#F6F4FF`) & Deep Indigo (`#292B59`) / Royal Indigo (`#5146A8`) with operational dispatch feeds, admin validation gate, and OTP verification cards.
   - **Admin Dashboard (`/admin`):** Cool White (`#F7F9FC`) & Midnight Navy (`#142536`) / Analytical Teal (`#168C87`) with high-density data tables, telemetry maps, audit logs, and one-click NGO approvals.

5. AUTO-ESCALATION & SMART SPLIT ENGINE (escalationEngine.js)
Tier 0 (T+0m): 3 km radius match using Haversine distance formula, filtered strictly by verified approved NGOs (is_approved = true), matching capacity, and ranked by composite score (distance + trust + response speed).   

Tier 1 (T+10m): Radius expands to 8 km if declined or timed out. Map ring transitions from 3km to 8km.   

Tier 2 (T+25m): Automatic quantity splitting across two smaller verified NGOs if no single NGO can handle bulk portions.   

Tier 3 (T+40m): Admin volunteer fallback dispatch.
